# 物語の書斎

小説の構想から執筆までを、作品ごとにひとまとめにする自分用の執筆アプリです。
PCでもスマホでも使えるPWA（ホーム画面に追加してアプリのように使えます）で、オフラインでも書けます。

## できること

- **作品一覧**：複数の作品を本棚のように並べて管理
- **概要**：タイトル・副題・ペンネーム・ジャンル・状態・ログライン・あらすじ・テーマ・メモ
- **表紙**：写真を選び、テンプレート（映画ポスター／文芸・縦組み／ミニマル／和・筆／ポップ）と色・グラデーション・粒子・書体・縦書きなどで表紙ポスターを作成
- **相関図**：人物をドラッグで配置、関係線（一方向・双方向）とラベル。人物を押すと履歴書風のプロフィール
- **構成**：起承転結・三幕構成・序破急・自由の型で物語の骨組みを整理
- **目次**：章の追加・並べ替え・文字数と原稿用紙換算
- **本文エディタ**：集中しやすいミニマルな画面。横書き／縦書き、明朝／ゴシック／手書き風、紙の色（白・生成り・夜）、自動保存
- **参考画像**：画像をまとめてタグ付け。表紙の背景にもそのまま使える
- **イメージ音楽**：曲名・URL・場面メモ、手元の音声ファイルの再生
- **書き出し**：本文をテキスト（.txt）で、作品まるごとをバックアップ（.json）で。バックアップは別の端末で読み込めます

## データの保存

いまはブラウザ内（IndexedDB）に保存しています。端末間の同期（Supabase）は次の段階で追加予定です。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド（dist/）
```

技術構成：Vite + React + TypeScript、Dexie（IndexedDB）、vite-plugin-pwa
